# Dataset notes

## Real source data used for training

`pima_indians_diabetes.csv` contains the Pima Indians Diabetes classification
dataset: 768 records, eight numeric measurements, and a binary `Outcome` label.
The original UCI data download endpoint at its historical URL currently returns
404. This project obtains the headerless 768-row file from the
[Jason Brownlee Datasets GitHub mirror](https://github.com/jbrownlee/Datasets/blob/master/pima-indians-diabetes.data.csv).
The source file has 768 lines and the expected eight measurements plus binary
label. Its Pima dataset attribution and original UCI reference are also recorded
in the [mirror's dataset notes](https://github.com/liquidcarrot/data.pima-indians-diabetes).
The project does not claim a separate license for the mirror file.

The included file is retained as received apart from adding a header row. Its
zero values in glucose, blood pressure, skin thickness, insulin, and BMI are
treated as missing measurements and median-imputed inside the training
pipeline. No records are synthesized or represented as new patients.

## Synthetic teaching data

`diabetes_synthetic.csv` is generated by `generate_data.py`. It is simulated
teaching data and is not part of the Pima dataset or used by default training.
Use `python generate_data.py` only when you want to demonstrate the synthetic
data generator.

## Limitations

The Pima dataset is a historical, narrowly defined cohort of adult women of
Pima heritage. Its model output is for a classroom exercise, is not a diagnosis,
and should not be generalized to other populations or used for care decisions.
